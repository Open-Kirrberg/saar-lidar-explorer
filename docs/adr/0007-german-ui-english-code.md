# 0007 · 🇩🇪 German UI, English code and docs

- **Status:** Accepted · 2026-11-01
- **Origin:** [PRD v1 §9](../history/prd-v1.md#9-decisions-log)

## Decision
- UI labels and `name_de` are German and address the user as **„Sie“**.
- Code, comments, docs and ADRs are English.

## Consequences
- ✅ Fits the local audience ([0014](0014-audience-scope-devices.md)); developers can work in English.
- ⚠️ Tests that assert UI strings are German.
