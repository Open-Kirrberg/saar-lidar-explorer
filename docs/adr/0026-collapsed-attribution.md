# 0026 · ©️ Collapsed attribution behind „© Quellen“

- **Status:** Proposed · 2026-11-04 (would supersede the footer rule in [0013](0013-attribution-every-source.md))
- **Origin:** v2 workshop · PRD open question Q-33

## Context
The 3-line attribution footer eats the game view, especially on phones.

## Proposal
A small, always-visible „© Quellen“ button in the 3D view (plus „© OSM“ on the minimap) opens the full list.

## To decide
Do dl-de/by-2-0 and ODbL accept a one-click attribution in an interactive 3D view? Check before v2 ships. Map apps commonly use an ⓘ toggle, but that needs confirming for these licences.
