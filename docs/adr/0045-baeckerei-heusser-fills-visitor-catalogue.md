# 0045 · Bäckerei Heusser — product fills and the visitor catalogue file

- **Status:** Accepted · 2026-11-05
- **Context:** Round 4a brought 103 products and their shapes; the shop was still empty like the walkthrough video. The app (round 5) needs one file per package with the info-card texts, the products and what counts for *entdeckt x / y*, without reading the zone's working catalogue.
- **Decision:**
  - **Fills** are data (`products/fill/<name>.json`, `bh-fill-v1`): slot id → `{product | ware, count}`. `morgens` (shortly after opening, every category) is the default, `feierabend` is empty like the video. One checker (`products/fill.py`) and the generator share the layout function, so a fill that passes the check is placed exactly as checked (category allowed, ≤ 3 × slot capacity, pieces fit the slot). Generic shelf goods (jars, cans, bottles, bags) are `ware` entries: no product card, no brands, no text; they are clickable through their shelf.
  - **Generator:** one node per filled slot, `produkt/<slot id>`, extras `{id: slot id, product | ware, count}` — one tap target per slot or basket, as the zone contract says. Heaped rolls use low-triangle variants (≤ 120), goods ≤ 160, the 300/800 per-piece rule stays.
  - **Visitor catalogue** `built/catalogue.json` (`sle-zone-catalogue-v1`): objects = built public rows with `info_de` except the `clickable: false` ones (facade, room shell: enclosing, so they would swallow every pick of their details from > 2.5 m), each grouped by its nearest listed ancestor, all products (prices only with `consent.prices`, ADR 0044), discoverable = the placed products + about 20 rows marked `discover` in the zone catalogue. `twin.catalogue` holds its path; older packages keep the format name there and simply show no cards. The capture stage copies only `built/…` JSON with the schema; `pipeline/zones.py` validates it.
- **Facade (same round, from the reviews):** muted three-tone plinth, solid red pilaster and quoins, constrained-Delaunay walls (no hairline cracks), and a gable whose back slope ends at eave height on the LoD2 hip over the chamfered corner. The ridge stays where LoD2 has it (off-centre, like the Street View photo); a symmetric gable would need geometry LoD2 does not have.
- **Consequences:** ≈ 119 k triangles for the morning twin (< 250 k), 2.7 MB packed. Rebuilding with `--update-catalogue` keeps `catalogue/slots.json` in step with the fixtures; fills must pass the check or the build stops.
- **Open:** the product `info_de` / `short_de` texts are the bakery's own copy (*ihr* / *unser*), not the twin's *du* (zone rule 8). They stay unchanged until the owners agree to a rewrite.
