# 🧱 Built twin generator

Turns the public Raumplan ([`../plan/`](../plan/README.md)) plus open survey data into the twin the zone shows ([ADR 0042](../../../docs/adr/0042-baeckerei-heusser-built-twin.md)): measured, stylised geometry in the look of [`../docs/style.md`](../docs/style.md). The capture mesh is only the hidden reference.

```bash
zones/baeckerei-heusser/build/run.sh                      # generator + pack into the zone package
zones/baeckerei-heusser/build/run.sh --update-catalogue   # also write status / dims / placement into ../catalogue/objects.json
                                                          # and the product slots into ../catalogue/slots.json
zones/baeckerei-heusser/build/run.sh --debug-slots --no-package   # magenta slot plates (debug only, never package them)
zones/baeckerei-heusser/build/run.sh --no-package         # generator only (build/out/)
zones/baeckerei-heusser/build/run.sh --no-lettering       # without the shop's own lettering (on by default, ADR 0044)
zones/baeckerei-heusser/build/run.sh --fill feierabend    # the fill a visit starts in (../products/fill/<name>.json; default morgens);
                                                          # every fill in ../products/fill/ is packed (the app's toggle)
cd pipeline && uv run python -I -m pytest -q -p no:cacheprovider ../zones/baeckerei-heusser/build
```

The packing step is the capture tool's stage `twin` (`tools/capture/run.sh baeckerei-heusser twin`). It needs a capture package in `app/public/data/zones/baeckerei-heusser/` (stage `package`, which runs `twin` itself when `[package.twin]` is in the TOML).

## Inputs → outputs

| Input | Used for |
|---|---|
| `../plan/raumplan-v0.json` (public) | Room, openings, porch and steps, fixtures, the Backstube entrance, the pickup cabinet (site fixture X1), passage up to `y ≤ 4.35` (ADR 0047) |
| `tools/capture/zones/baeckerei-heusser.toml` `package.scale_factor` | The one scale factor (must equal the plan's `scale.factor`) |
| `data/work/overall/dtm.tif` (DGM1) | Ground patch, street and spawn heights |
| `data/raw/lod2/sl/*.gml.gz` (LoD2, parsed with `pipeline/buildings.py`) | The shop's envelope and roof, neighbour blocks |
| `data/raw/osm/overall.json` (OSM highways) | Carriageway and pavement |
| `../catalogue/objects.json` | Node names must be catalogue ids („no catalogue entry, no geometry“); rows with `info_de` go into the visitor catalogue |
| `../products/products.json`, `../products/fill/*.json` | The products and where they lie (`bh-fill-v1`, each fill checked against this build's slots before placing); every fill is packed, `--fill` picks the start state |

`build/out/` (git-ignored): `twin.glb` and `nav.glb` (raw: float32, unlit, `COLOR_0` = baked light), `report.json` (node list, triangles, bbox, hashes, the fill), `slots.json` (product slots, `bh-slots-v1`), `catalogue.json` (visitor catalogue, `sle-zone-catalogue-v1`, with the guided tour from `catalogue/tour.json` as `tour`; `tour_block` fails the build on a broken stop, `test_tour.py`), `package.json` (manifest fragment for the packer, incl. `files`), `cache/` (LoD2/OSM extracts). Packed result: `app/public/data/zones/baeckerei-heusser/built/{twin,nav}.glb` + `built/catalogue.json`, zone.json with the `twin` block and `twin.catalogue = "built/catalogue.json"` (`docs/zone-contract.md`).

## Rules

- Deterministic: same inputs → byte-identical GLBs (tested).
- One scale factor, applied to mesh-derived values only; survey data never scales (tested).
- Nothing beyond the privacy line (passage `y > 4.35`, ADR 0047), no node named after the residents' part, the cabinet in front of the line, and no walkable floor behind the counter (tested).
- Budget (style.md): < 300 k triangles in total, fixtures ≤ 5 k, appliances ≤ 2 k, containers/signs ≤ 1 k per object (checked by the build and the tests). v0: ≈ 24 k triangles, 0.5 MB packed; round 3: ≈ 34 k triangles; round 3b (facade): ≈ 52 k triangles, 1.3 MB packed; round 4b (morning fill): ≈ 119 k triangles, 2.7 MB packed; wave A: ≈ 125 k, 2.8 MB; wave B (4 dense bread tiers, 28 price cards): ≈ 152 k triangles, 3.2 MB packed. Products: ≤ 300 per piece (≤ 800 for the `LARGE` cakes), ≤ 120 per heaped roll, ≤ 160 per generic good.
- Raw data is parsed, never executed (`python -I`).
- Round 4 facade: plinth slips in three muted tones (`facade.plinth_tone`), pilaster and SSW corner quoins solid red sandstone. The large LoD2 walls are triangulated by constrained Delaunay (`geom.triangulate(cdt=True)`): earcut joined the collinear sill corners of the upper windows into a dropped zero-area triangle, a hairline crack on the street wall. Gable: LoD2 has a hip over the chamfered back corner (L8) and the ridge 1.3 m behind the middle of the end wall; the ridge stays where LoD2 has it (no invented geometry), the hip over the chamfer stays, and the gable's back slope now runs from the ridge down to that hip's eave corner, so both gable eaves sit at eave height (`Gable.corner`). That matches the Street View photo: ridge off-centre towards the back, steeper back slope, level eaves. A truly symmetric gable would need a ridge LoD2 does not have.
