# Schloss Karlsberg — 3D reconstruction (living document)

Sub-project of the Saar LiDAR Explorer: a researched, georeferenced 3D reconstruction of
Schloss Karlsberg near Homburg (Duke Karl II. August of Pfalz-Zweibrücken, built 1778–1788,
burnt 1793) and all buildings of the residence, plus plan documents (Flurplan/Lageplan,
Grundrisse, Ansichten, Schnitte). Goal: "discover the castle" — fly over it and walk into it,
first in a standalone viewer, later as a layer in the explorer map.

## Run
```bash
cd schloss-karlsberg && pnpm install && pnpm run dev     # viewer → http://localhost:5260/
pnpm run test      # vitest (model, plans, viewer)
pnpm run build     # tsc --noEmit + vite build
pnpm run plans     # 30 sheets → plans/out/*.svg|pdf, previews → docs/plans-preview/
pnpm run export    # glTF per building (lod0/lod1) + site → model/out/
pnpm run export:explorer   # light layer for the explorer → ../app/public/data/shared/karlsberg1789/ (glb + footprints + index)
pnpm exec tsx scripts/catalogue-v2/build.ts   # rebuild model/catalogue.json (deterministic)
cd ../pipeline && uv run python -I ../schloss-karlsberg/scripts/prepare-terrain.py   # viewer terrain (1789 + 2025)
```

**Viewer keys:** click the canvas for mouse look (pointer lock) · WASD / arrows move · Q/E (PageDown/PageUp) down/up in Fliegen · Space jump in Gehen · Shift fast · F Fliegen · G Gehen · M Zurück zur Karte (explorer at the same pose) · P Foto (still at 2× or 3×, "Tiefenunschärfe" optional, saved as PNG with the attribution and "Rekonstruktion – Hypothese" burned in). **▶ Rundflug** in the panel plays a ~70 s guided flight in six shots (Anflug, Ehrenhof, Garten, Galerie, Orangerie, Goldene Stunde) in the Kino look with letterbox and German captions naming each building's confidence; Esc or any key, click, wheel or touch stops it and restores the previous time of day, look and pose. ## Principles
- **Evidence first.** Every building/part carries a confidence level and its sources
  (historic plans, views, excavations, LiDAR remains, comparable buildings). Where we infer,
  we say so. The model is a *hypothesis*, not a record.
- **Georeferenced.** EPSG:25832, heights DHHN2016, local frame as in `../docs/data-contract.md`
  (`x = E − E0`, `y = h`, `z = −(N − N0)`, karlsberg AOI origin E0 = 381000, N0 = 5465000),
  true heights, so the model drops into the explorer without transforms.
- **Heritage law.** The site is a protected monument (SDschG Saarland / DSchG RLP). The model
  and plans are for looking, not for digging; no detector or excavation guidance.
- **Data/media out of git.** Downloaded videos, frames, Video2World outputs and big binaries
  stay in git-ignored folders; only sources, specs and small derived docs are committed.
